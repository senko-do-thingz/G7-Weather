Slide 03 / 08 Part 1 - Introduction
Overview

What is G7 Weather Service?

A Java backend application that retrieves current weather information from the OpenWeather API

☕
Java Backend
Built with JDK 17 and managed by Maven. Clean, modular architecture with separated concerns.
🌤️
OpenWeather API
Integrates with the OpenWeather REST API to fetch real-time weather data for any city worldwide.
🧪
JUnit 5 + Mockito
Comprehensive testing with 25 unit tests covering all edge cases. Mockito mocks the HTTP layer.
⚙️
GitHub Actions CI/CD
Automated pipeline: build, test, generate reports, and package into a JAR artifact on every push.
⛈️

What We'll Demonstrate

Automated Build

Slide 06 / 08 Part 2 - CI/CD
Concept

What is CI/CD?

The automated process from pushing code to delivering a deployable application

🔄
Continuous Integration
Whenever developers push new code to the repository, an automated process builds the project and runs tests to make sure changes do not introduce problems.
🚀
Continuous Delivery
After tests are completed, the application is packaged into a JAR file and uploaded as a GitHub artifact - ready for further deployment.

Slide 07 / 08 Part 2 - CI/CD
Benefits

Why CI/CD?

Key benefits and how our workflow is triggered

🐛
Detect Problems Early
Bugs are caught immediately when code is pushed - before they reach production or other developers.
⚡
Reduce Manual Work
No need to manually build, test, or package. The entire process runs automatically on every push.
🤝
Team Consistency
Every team member uses the same automated process to verify code - ensuring consistent quality.

Workflow Triggers

🔀
Push to main
Triggers on every push to main branch
🌿
Push to develop
Also triggers on develop branch pushes
📝
Pull Requests → main
Runs for PRs targeting the main branch
